# Analista Datos

Recolecta estados financieros 2023-2025, documenta variables, limpia datos y separa fuentes oficiales de supuestos. Producto: CSV, diccionario de datos y validación de cifras.

## Reglas
- Registrar fuente de entrada.
- No inventar datos.
- Entregar conclusiones accionables.
- Reportar incertidumbre cuando el dato sea supuesto.
